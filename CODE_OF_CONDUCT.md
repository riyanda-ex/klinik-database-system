# Kode Etik Kontributor - Klinik Database System

## Janji Kami

Kami berkomitmen membuat lingkungan yang ramah, aman, dan profesional
untuk semua orang, tanpa memandang latar belakang, pengalaman,
atau tingkat keahlian.

Proyek ini adalah tentang data kesehatan. Kepercayaan dan
keamanan pasien adalah yang utama.

## Perilaku Yang Diharapkan

- Gunakan bahasa yang sopan, jelas, dan profesional
- Hargai pendapat, pengalaman, dan waktu orang lain
- Fokus kritik ke kode / skema, bukan ke orangnya
- Bantu pemula yang baru belajar database / SQL
- Utamakan keamanan data pasien di atas segalanya

## Perilaku Yang Dilarang Keras

1. **DILARANG upload data pasien asli.**
   Dilarang keras mengupload nama pasien asli, NIK asli,
   No. RM asli, No. BPJS asli, foto KTP, PDF rekam medis,
   atau backup database asli ke repo ini, ke Issue, atau ke Pull Request.
   Gunakan selalu data sintetis: `PAS-001`, `SHA2('...')`, `dr. Contoh`.

2. Dilarang bahasa kasar, pelecehan, diskriminasi, atau ancaman.

3. Dilarang spam, promosi yang tidak relevan, atau mengirim
   link berbahaya.

4. Dilarang mengklaim skema ini sebagai sistem produksi RS.
   Skema ini adalah demo portfolio & pembelajaran.

## Cara Melaporkan Pelanggaran

Jika kamu melihat ada yang upload data pasien asli atau
melakukan pelecehan:

1. Jangan balas dengan emosi
2. Screenshot buktinya (jangan sebar data asli tersebut)
3. Laporkan ke pemilik repo melalui GitHub secara privat
4. Pemilik repo akan menghapus konten tersebut secepatnya

## Penegakan

- Pelanggaran pertama: ditegur secara privat + konten dihapus
- Pelanggaran berulang / upload data asli: diblokir dari repo ini
- Jika pelanggaran berupa data pasien asli, data tersebut
  akan dihapus permanen dari riwayat commit secepat mungkin

## Berlaku Untuk

Kode etik ini berlaku untuk semua orang di repo ini:
Issue, Pull Request, Diskusi, dan semua interaksi lainnya.

Terima kasih sudah menjaga repo ini aman dan profesional.
