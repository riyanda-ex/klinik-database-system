# Klinik Database System

Sistem database sederhana untuk klinik.

### Masalah
Pencatatan pasien dan stok obat di klinik masih manual, rawan salah dan lambat saat dicari.

### Solusi
Saya membuat database MySQL dengan 4 tabel utama: pasien, dokter, obat, dan kunjungan. Dilengkapi query untuk rekap harian dan cek stok.

### Teknologi
- MySQL / SQL
- Database Design

### Fitur
- Manajemen data pasien
- Rekap kunjungan harian
- Peringatan stok obat menipis
- Riwayat kunjungan pasien
